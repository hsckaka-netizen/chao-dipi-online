# 炒地皮头像框设计与交付规范

> 版本：`2026-08-11-v7`。本规范同时约束头像框素材、管理后台验收和游戏界面叠加行为。

## 1. 核心定义

头像框是一张独立的透明前景 PNG。素材自身完成框体、徽记、装饰和必要特效的设计；除设计本体外，其他区域必须真实透明。

- 运行时头像图片在下，完整头像框素材在上。
- 程序不分析素材中的框体、装饰或透明区域，只按统一规则完整、等比叠加。
- 禁止为单个主题增加缩放、位移、裁切或 CSS 补偿。
- 素材不得自带头像、示例照片、方形底板或不透明背景。

## 2. 固定几何规范

| 项目 | 必须规则 |
| --- | --- |
| 画布 | `512 × 512 px`、sRGB、8-bit RGBA、非隔行 PNG |
| 虚拟框架 | 约为 `x=70..442`、`y=70..442` 的 `372 × 372 px` 正方形；该框架不导出，专门用于与头像外沿对齐 |
| 框体基准 | 框体沿虚拟框架四边设计，四边形成连续闭合的视觉路径 |
| 向内设计 | 可从虚拟框架向头像内延伸，但不得进入头像核心区 |
| 头像核心区 | `x=128..384`、`y=128..384` 的 `256 × 256 px` 区域必须完全透明 |
| 向外设计 | 可从虚拟框架向外延伸，但必须保留画布边缘透明区 |
| 画布边缘 | 所有可见像素位于 `x/y=8..504`，四边至少 `8 px` 完全透明 |
| 文件大小 | 不超过 1.2 MB，不带动画 |

使用 [头像框坐标模板](assets/avatar-frame-template.svg) 起稿。`GUIDES_DO_NOT_EXPORT` 只用于对齐，导出前必须隐藏。

## 3. 视觉设计规则

- 上下承担主要设计量，两侧使用较窄的连接导轨，避免四边等宽的厚重方框。
- 武器、藤蔓、能量带、闪电或火焰可以替代局部实体导轨，但必须与两端明确连接。
- 零散粒子不能单独充当边框，也不得穿过头像核心区。
- 顶部装饰向顶部和两侧发展；底部元素可居中，也可拆分到左下和右下。
- 数字、字母、徽记和人物主体必须保持自然纵横比，不得拉宽或压扁。
- 缩小到紧凑头像时，仍应通过轮廓、主色或独有符号识别主题。

## 4. 界面尺寸与预留区域

“头像尺寸”指头像外沿正方形，该外沿与素材中的虚拟框架完全重合；向内和向外的可见设计都只是额外覆盖，不能用来推算头像边界。“展示区”用于完整显示头像框素材。有无头像框都使用同一展示区，不得在佩戴后改变布局占位。

运行时完整展示区固定为头像尺寸的 `1.376` 倍，对应整张 `512 × 512 px` 素材与约 `372 × 372 px` 虚拟框架的比例。

| 界面 | 头像尺寸 | 完整展示区 |
| --- | ---: | ---: |
| 顶栏、排行榜、后台账号列表 | 38 px | 52.288 px |
| 排行榜移动端 | 34 px | 46.784 px |
| 房间列表、准备页、观战列表、普通资料区 | 48 px | 66.048 px |
| 数据详情页 | 76 px | 104.576 px |
| 牌桌其他玩家 | 80 px | 110.08 px |
| 本人手牌区桌面端 | 104 px | 143.104 px |
| 本人手牌区移动端 | 72 px | 99.072 px |
| 商城主预览 | 88 px | 121.088 px |
| 商城小预览 | 38 px | 52.288 px |

- 展示区及其父布局必须允许完整框体显示，不得裁切顶部、底部或两侧。
- 昵称、积分和操作按钮按完整展示区避让，不得仅按头像尺寸计算间距。
- 图层顺序固定为：背景 < 头像图片 < 头像框 < 明确允许覆盖的状态标识和牌局特效。
- 头像加载完成、页面刷新或局部重绘都不得改变图层顺序。

## 5. 后台上传与验收

- 商城、我的头像框和管理后台只展示头像框透明素材本身，不在这些选择或管理区域叠加示例头像。
- 选择新 PNG 后先在本地展示素材原图，以及紧凑、牌桌和大展示区中的纯素材缩放效果，再允许上传。
- 服务端强制校验文件格式、画布尺寸、编码、文件大小、四边透明区和中央核心透明区。
- 连续闭合、主题辨识和是否存在无关像素由管理员通过预览人工确认。
- 校验通过后创建新头像框商品，默认为草稿；修改素材使用新的主题编号或版本，不覆盖旧资源地址。

## 6. 交付验收清单

- [ ] 头像框四边沿虚拟框架闭合，没有无承接断口。
- [ ] 中央 `256 × 256 px` 核心区全透明，四边 `8 px` 全透明。
- [ ] 没有头像、底图、棋盘格、黑底或无关半透明色块。
- [ ] 实装时头像图片始终在下，头像框始终在上。
- [ ] 紧凑、普通、牌桌和大尺寸中框体都完整可见，不被父容器、昵称或头像裁切。
- [ ] 有框与无框切换时，头像大小和页面布局占位不变。
