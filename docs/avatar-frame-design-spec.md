# 炒地皮头像框设计与交付规范

> 版本：`2026-08-11-v4`。本规范用于委托内部或外部设计师制作新的头像框素材。所有“必须”项均为上线验收项。

## 1. 设计目标

头像框不是一张缩小的海报，而是玩家在牌桌上的长期身份标识。合格素材必须同时做到：

1. 在 38 px 房间列表中能凭轮廓或主色认出主题。
2. 在 80–104 px 牌桌头像中有明确的价值感和主题细节。
3. 不遮住头像五官，不与昵称、当前回合、战神和牌运标记抢层级。
4. 在浅色、深色和绿色牌桌背景上都能看清边界。

## 2. 交付文件

| 文件 | 要求 |
| --- | --- |
| 最终素材 | `avatar-frame-<theme-id>.png`；聊天生成后由后台上传 |
| 可编辑源文件（可选） | Figma、PSD 或 AI 任一；需要继续迭代时再提供，图层需命名并保留可编辑结构 |
| 设计说明（可选） | 主题名、`theme-id`、主色、识别符号、素材授权说明 |

- `theme-id` 只允许小写英文字母、数字和连字符，例如 `jade-dragon`。
- 不得直接使用未获授权的品牌标志、赛事标志、明星肖像或影视游戏角色。

## 3. 画布和坐标

统一坐标系为 512 × 512 px，原点在左上角。

| 区域 | 坐标 | 规则 |
| --- | --- | --- |
| 画布 | `x=0..512, y=0..512` | sRGB、透明背景 |
| 外边界 | `x=8..504, y=8..504` | 所有可见像素必须在此范围内 |
| 标准正方形内开口 | `x=96..416, y=96..416` | 固定 320 × 320 px 且必须完全透明；四条内沿不得侵入或按主题自行缩放 |
| 五官核心安全区 | `x=128..384, y=128..384` | 固定 256 × 256 px，必须完全透明 |
| 内开口保护区 | 标准开口完整区域 | 所有主题元素、粒子、投影和发光均不得进入，确保头像始终按同一正方形适配 |
| 顶部主设计区 | `x=20..492, y=8..96` | 主要视觉重量放在这里，体量从标准开口上沿向画布顶部与两侧发展 |
| 左右窄导轨 | `x=40..96`、`x=416..472` | 推荐可见宽度 24–40 px，内沿统一落在 `x=96` 与 `x=416` |
| 底部主设计区 | `x=20..492, y=416..504` | 可居中或分布到左右两侧；基础内沿统一落在 `y=416` |

固定几何换算：基础内框距画布四边均为 96 px；扣除 8 px 透明边距后，外框相对基础内框每侧最多向外扩 88 px。整个 320 × 320 px 内开口必须完全透明，任何装饰、投影、粒子或能量效果均不得进入。

使用 [头像框坐标模板](assets/avatar-frame-template.svg) 开始设计。模板中的 `GUIDES_DO_NOT_EXPORT` 图层只用于对齐，导出前必须隐藏。

### 头像安全区

- 标准正方形内开口的四条基础内沿必须分别对齐 `x=96`、`x=416`、`y=96`、`y=416`；主题不同不能改变框体开口尺寸。
- 整个标准内开口内所有像素的 Alpha 必须为 0，不允许半透明雾、投影、光斑、粒子或纹理侵入。
- 顶部短尖、局部能量和底部元素只能贴近内沿并向框外发展，不得进入标准内开口。
- 四条内沿必须保持正方形，不得形成长方形、倒凸形或刘海形。
- 抗锯齿、投影和能量效果不得越过五官核心安全区边界。
- 头像由系统单独裁切和显示，素材不得自带头像、底板或示例照片。

## 4. 视觉结构

推荐采用“上下有设计、两侧轻量”的结构，避免四边等宽导致头像被厚框包住。每款头像框必须包含三个层级：

1. **上下主轮廓**：顶部冠饰和底部底座承担主要设计感，缩到 38 px 时仍能看出外形。
2. **两侧窄导轨**：只负责连接和稳定轮廓，建议母版可见宽度 24–40 px；不得做成与上下同宽的厚重立柱。
3. **主题识别点**：顶部或底部至少一个唯一符号；不能只靠换颜色区分主题。
4. **质感细节**：只服务于 80–104 px 大尺寸，不承担主要识别。

框体必须沿顶部、左右和底部形成连续闭合的视觉路径。主题元素、武器、藤蔓或成束能量效果可以包裹边框，也可以局部替代实体导轨，但替代物必须明确连接断点两端；不得留下没有任何承接关系的透明空档。粒子只能作为连续能量束或密集效果带参与连接，零散火花不能单独充当边框。

所有主题共享同一个完全透明的 320 × 320 px 正方形基础开口。主题差异只能发生在开口外侧；不得改变开口宽高或对素材做非等比压缩。

### 推荐比例

- 视觉重量约 65% 放在顶部和底部，约 35% 放在左右两侧。
- 左右导轨建议只占画布宽度的 5%–8%；除连接节点外，不要连续超过 40 px 厚。
- 顶部和底部允许向画布外缘横向展开，但必须用透明留白收尾，不能形成完整的不透明方框。
- 顶部增加细节时，必须从头像上沿向画布顶部和左右两侧生长；不得通过向头像内部加深来制造“更高”或“更丰富”的感觉。
- 顶部主视觉不强制居中，可以偏置在左上或右上；单侧构图必须附着在连续上沿，并向画布顶部及同侧外缘生长。靠头像一侧应短、浅、利落，不得向头像中心垂落成“刘海”。
- 底部不强制使用中央大徽记。为避免多款头像框产生相同的上下中轴构图，可把两个主题元素分布到左下和右下，中部只保留低矮连接结构。
- 底部主题元素应优先向画布底边和左右外缘生长；不得通过向头像内部抬高大面积底座来增加存在感。
- 左下和右下元素不要求镜像或同类，只要求视觉重量整体平衡；可用大小、明暗、粒子密度或连接结构补偿不对称。
- 同一批头像框应混用“底部居中”和“底部左右分布”两类构图，不能全部采用相同模板。
- 四角用于连接，不作为四个同等重量的装饰中心；避免“每个角都堆一个大宝石”。

### 局部元素效果

- 闪电、火焰、水花、叶片和元素火花可以较明显地围绕顶部徽记或底部主题元素出现，用于强化职业和主题辨识。
- 效果必须绑定明确锚点，优先留在顶部、底部或侧轨外缘；不得让粒子均匀散布整圈，也不得穿过头像中心。
- 粒子可以形成疏密变化和短距离运动轨迹，但密集区应朝画布外缘扩散，靠头像一侧逐渐收敛。
- 高亮效果仍计入可见框体，高亮面积建议不超过 18%；禁止整圈霓虹、大片白光、雾化遮罩和持续频闪。
- 静态框使用凝固的局部效果；动态框的效果范围和频率另行确认。

### 最小尺寸

- 顶部和底部关键轮廓或色带：母版不得细于 20 px，基础内沿必须贴合标准正方形开口。
- 两侧连续导轨：建议 24–40 px，不得超过 48 px。
- 次级描边：母版不得细于 12 px。
- 装饰细节：母版不得细于 8 px；小于 8 px 的细节不计入验收。
- 最细高光不得连续包围整个外框，避免缩小后形成刺眼白边。

### 色彩与质感

- 建议使用 2–3 个主色和不超过 2 个强调色。
- 必须同时提供深、浅边缘对比：亮主题需要暗轮廓，暗主题需要克制的亮轮廓。
- 禁止大面积纯白外发光、整圈霓虹、满框高频闪点、过度锐化和照片噪点。
- 金属、宝石和火焰可以使用，但需要保留低亮度基底；高亮面积建议不超过可见框体的 18%。
- 系统会在运行时增加轻量主题色环境光，素材本身不要烘焙超过 24 px 的大范围光晕。

## 5. 与游戏界面的关系

| 界面 | 头像基准 | 框体实际显示约 | 验收重点 |
| --- | ---: | ---: | --- |
| 房间列表、数据榜单 | 38 px | 约 50 × 55 px | 轮廓和主色可辨，昵称不被遮挡 |
| 普通资料区 | 48 px | 约 63 × 69 px | 头像仍是主体，不显得拥挤 |
| 牌桌其他玩家 | 80 px | 约 106 × 115 px | 主题有价值感，道具标记仍清楚 |
| 本人手牌区 | 104 px | 约 137 × 150 px | 细节完整，不被父容器裁切 |

- 框体在前景、头像在后景；素材不得依赖与头像图片混合才能成立。
- 系统会把每张已验收素材的 320 × 320 px 标准开口归一化为同一个显示尺寸；禁止依赖单款素材的额外缩放修正开口。
- 运行时以完整的 512 × 512 px 框体画布作为唯一定位基准：框体图层填满该画布；头像图层严格落在画布 `x/y=96..416` 的 320 × 320 px 开口，即画布边长的 62.5%（四边各留 18.75%）。为保持未装备时的头像内容尺寸，完整画布固定按头像内容尺寸的 160% 显示；不得再按旧外框视觉尺寸估算、把框体作为溢出伪元素，或对头像做二次比例补偿。框体使用实际前景图片层，始终在头像图层之上；头像不得自带圆角、描边或投影覆盖内沿。
- 战神标记位于右上，牌运标记位于左上。顶部中央可以做主冠饰，但两个上角不能同时堆满高亮细节。
- 昵称通常位于头像右侧或下方。任何横向装饰都必须留在 512 px 画布内，由系统预留外扩空间。

本节只说明素材的使用环境，不作为每次出图必须重新执行的浏览器验收。只要素材通过第 3、4、7、8 节的固定坐标和图片检查，即可进入接入流程；主题接入未修改头像容器时，不要求重复进行浏览器尺寸调试。

## 6. 动态素材

- 常规头像框只交付静态 PNG/WebP，不得擅自提交 GIF。
- 动态框属于单独商品等级，必须先确认动效方案再制作。
- 动效只允许局部呼吸、粒子或流光；单次循环建议 2.4–4 秒，不允许整框缩放、频闪或持续高亮跳变。
- 动态框必须同时交付静态备用图；系统开启“减少动态效果”时只显示静态图。

## 7. 导出要求

- 尺寸固定 512 × 512 px，8-bit RGBA，sRGB。
- 背景和头像开口必须真实透明，不得以黑色、白色或棋盘格代替。
- 管理后台上传上限为 1.2 MB；不得携带多余元数据。
- 聊天生成后直接导出 PNG 并在“钻石与商城”的“上传聊天生成头像框”中提交；后台会逐像素校验尺寸、RGBA 与透明安全区，默认创建为草稿。
- 通过验证后素材存入 Storage，并以内容版本 URL 关联商城商品；不再逐个移入 Git 或改前端代码。

## 8. 图片验收

头像框按最终 PNG 文件直接验收，不依赖游戏页面。可使用 [头像框本地自检页](avatar-frame-preview.html) 辅助读取像素，但它不是必需交付物。管理后台会自动执行固定坐标检查；人工仍需确认视觉效果。必须检查：

- 文件格式、画布尺寸和文件大小。
- 8 px 外边距是否透明。
- 320 × 320 px 基础开口是否为正方形且四条内沿坐标一致。
- 256 × 256 px 五官核心安全区是否完全透明。
- 框体四条基础内沿是否落在同一个 320 × 320 px 正方形上，外扩和侵入是否均未越界。

坐标检查通过后仍需直接查看成图确认以下项目：

- [ ] 38 px 时不看名称也能区分该主题。
- [ ] 头像五官和主体没有被框体遮住。
- [ ] 与规范母版叠加后，四条基础内沿严格落在同一个 320 × 320 px 正方形上。
- [ ] 上方两个道具标记出现时，主题仍可识别。
- [ ] 数字、字母、徽记、徽章和人物主体保持自然纵横比；禁止横向拉宽、纵向压扁或透视变形。该项必须直接查看 512 px 原图，不能只依赖坐标校验。
- [ ] 框体与昵称之间至少有清晰视觉间隔。
- [ ] 无整圈刺眼白光、脏边、黑底或半透明方块。
- [ ] 四角没有被裁切，缩小时没有破碎锯齿。
- [ ] 浅色、深色、牌桌绿色背景均清楚。
- [ ] 文件名、`theme-id` 和设计说明一致。

## 9. 可直接复制的委托简报

> 请按《炒地皮头像框设计与交付规范》制作一款 `<主题名>` 头像框。使用 512 × 512 px 透明画布，基础内开口固定为 x=96..416、y=96..416 的 320 × 320 px 正方形，整个内开口必须完全透明。所有可见像素位于 x=8..504、y=8..504，外框每侧最多外扩 88 px；主题元素只能向开口外侧发展，不得改变开口尺寸或宽高比。顶部体量从标准开口上沿向画布顶部和两侧发展，底部可居中或把主题元素分布到左右两侧。框体四边必须闭合连续；闪电、火焰等局部效果必须绑定主题元素且不得进入头像。主题必须在 38 px 时凭轮廓或主色可识别，不得只靠微小纹样；禁止整圈霓虹和刺眼白光。请直接导出符合固定坐标的最终 PNG，供后台上传校验；源文件和设计说明按需提供，不要求浏览器实装预览。
